# GameVault - 제품 요구 사항 문서 (PRD)

## 프로젝트 개요
GameVault는 개인의 게임 라이브러리를 체계적으로 관리하는 웹 애플리케이션입니다. 프리미엄 게임 런처 스타일의 UI로 게임 정보를 등록, 검색, 필터링하고 플레이 상태와 평점을 관리할 수 있습니다.

## 프로젝트 목적
- 개인 게임 라이브러리 통합 관리
- 게임 진행률 추적 (백로그, 진행 중, 완료, 일시 중단)
- 게임별 평점 및 리뷰 기록
- 사용자별 독립적인 데이터 관리
- 직관적이고 아름다운 UI 제공

## 기술 스택
- **프런트엔드**: Next.js 15 + App Router + TypeScript
- **스타일링**: Tailwind CSS (다크 모드)
- **데이터베이스**: Supabase PostgreSQL
- **인증**: Supabase Auth (이메일)
- **SDK**: @supabase/supabase-js, @supabase/ssr

## 핵심 기능

### 인증 (MVP)
- 이메일 회원가입
- 이메일 로그인
- 로그아웃
- 세션 유지
- 인증되지 않은 사용자 접근 제한

### 게임 라이브러리
- **CRUD 작업**
  - 게임 등록 (제목, 플랫폼, 커버 이미지 URL)
  - 게임 목록 조회 (사용자별 필터링)
  - 게임 상세 정보 조회
  - 게임 수정
  - 게임 삭제

- **게임 상태 관리**
  - backlog: 플레이 예정
  - playing: 플레이 중
  - completed: 플레이 완료
  - paused: 일시 중단

- **평점 및 리뷰**
  - 1~5점 평점
  - 개인 리뷰 텍스트

- **검색 및 필터**
  - 게임 제목 검색
  - 플레이 상태별 필터
  - 최신 등록순 정렬

### 통계 대시보드
- 전체 게임 수
- 플레이 중인 게임 수
- 완료한 게임 수
- 플레이 예정 게임 수

## 사용자 스토리

### US-001: 게임 라이브러리 생성
사용자로서 나는 새로운 계정을 만들어 내 게임 라이브러리를 시작하고 싶다.

### US-002: 게임 추가
사용자로서 나는 내가 소유한 게임을 라이브러리에 추가하고 싶다.

### US-003: 게임 상태 추적
사용자로서 나는 게임의 플레이 상태(플레이 예정, 진행 중, 완료, 일시 중단)를 추적하고 싶다.

### US-004: 게임 평가
사용자로서 나는 완료한 게임에 평점을 부여하고 개인적인 리뷰를 작성하고 싶다.

### US-005: 라이브러리 관리
사용자로서 나는 게임을 검색하고, 상태별로 필터링하고, 필요시 삭제하고 싶다.

## MVP 범위

### 포함됨
- 사용자 인증 (회원가입, 로그인, 로그아웃)
- 게임 CRUD 작업
- 게임 상태 관리
- 평점 및 리뷰
- 검색 및 필터 기능
- 통계 대시보드
- 반응형 웹 디자인
- 보안 (RLS, 세션 관리)

### 제외됨 (향후 버전)
- 외부 게임 검색 API 통합
- 게임 태그 시스템
- 소셜 기능 (친구, 공유)
- 클라우드 백업
- 모바일 앱
